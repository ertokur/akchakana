# Акчакана — учёт личных финансов

Офлайн-PWA для учёта доходов, расходов, счетов, бюджетов и долгов. Устанавливается на Android и
iOS как приложение с главного экрана, работает без интернета, все данные хранит только на
устройстве (IndexedDB). Нет серверов, банковских API, аналитики и трекинга.

**Открыть:** https://ertokur.github.io/akchakana/

## Возможности

- **Операции** по дням с итогами дня; период: день, неделя, месяц, год или произвольный; сводка
  доходов, расходов и баланса; фильтр по счёту; свайп влево — удалить (с отменой).
- **Добавление операции** в нижней шторке: калькулятор (`+ − × ÷`, вычисления в целых), сетка
  категорий с подкатегориями, счёт, дата и время, заметка, теги. Расход, доход, перевод (в том
  числе между счетами в разных валютах).
- **Счета**: наличные, карта, накопления, кредитная карта; валюта, начальный баланс, цвет,
  иконка, скрытие. Общий баланс по валютам. **Долги**: «мне должны» и «я должен» с погашениями.
- **Категории**: стандартный набор, свои категории и подкатегории, скрытие, порядок.
- **Обзор**: кольцевая диаграмма по категориям, столбцы по дням или месяцам, сравнение с прошлым
  периодом, табличный вид.
- **Бюджеты**: месячный лимит на всё или на категорию, прогресс, предупреждения при 80 % и при
  превышении.
- **Регулярные платежи**: напоминание или автоматическое добавление операции, уведомления через
  Notification API.
- **Импорт** резервной копии 1Money и CSV, **экспорт** всех данных в CSV, напоминание об
  экспорте раз в месяц.
- **Настройки**: валюта по умолчанию, часовой пояс (по умолчанию `Asia/Bishkek`), первый день
  недели, тема (светлая, тёмная, системная), PIN-код, сброс данных.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev        # режим разработки, http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # локальный просмотр собранной версии (с service worker)
npm run test       # тесты Vitest
npm run lint       # ESLint
npm run icons      # перегенерировать PNG-иконки из public/logo.svg
```

Сборка `dist/` — статические файлы; их можно разместить на любом хостинге с HTTPS (PWA и
service worker требуют HTTPS, кроме `localhost`). Маршрутизация через `#/…`, поэтому настройка
переписывания URL на сервере не нужна.

## Публикация

При каждом пуше в `main` GitHub Actions (`.github/workflows/pages.yml`) запускает lint и тесты,
собирает приложение с `BASE_PATH=/<имя репозитория>/` и публикует его на GitHub Pages.
Локально путь по умолчанию — `/`.

## Установка на телефон

**Android (Chrome).** Откройте адрес приложения, затем меню **⋮ → «Установить приложение»**
(или «Добавить на главный экран»). Иконка появится на главном экране, приложение откроется в
отдельном окне без адресной строки.

**iOS (Safari).** Откройте адрес приложения в Safari, нажмите **«Поделиться» → «На экран
„Домой“»** → «Добавить». Уведомления на iOS работают только у установленного так приложения
(iOS 16.4 и новее).

После первого открытия приложение работает без интернета. Когда выходит новая версия, внизу
появляется сообщение «Доступна новая версия» с кнопкой «Обновить».

## Где хранятся данные и почему нужен экспорт

Данные лежат в IndexedDB браузера на этом устройстве. Браузер может очистить хранилище (нехватка
места, очистка данных сайта, на iOS — долгое неиспользование). Приложение просит браузер
сделать хранилище постоянным и раз в 30 дней напоминает сделать экспорт. Храните файл экспорта
в надёжном месте: из него восстанавливаются все данные.

PIN-код защищает от случайного доступа к открытому приложению, но не шифрует данные. Забытый
PIN восстановить нельзя: можно только сбросить данные и импортировать резервную копию.

## Импорт

**Настройки → Импорт** (или «Импортировать резервную копию» на первом экране). Формат определяется
по содержимому файла, а не по имени. Перед записью показывается сводка: число операций, счетов и
категорий, период, валюта, ошибки и предупреждения. Данные записываются одной транзакцией только
после нажатия «Импортировать».

### Резервная копия 1Money

Файл копии — база SQLite без расширения (начинается с `SQLite format 3`). Она открывается
только на чтение, в памяти, и никуда не отправляется.

- Операции берутся из последнего ежедневного снимка; записи, которых в нём нет, считаются
  удалёнными.
- Счета и категории определяются по ссылкам из операций; скрытые (архивные) импортируются
  скрытыми; порядок категорий берётся из копии.
- Суммы читаются как строки и переводятся в минимальные единицы без потерь. Отрицательная сумма —
  возврат, сохраняется как есть с пометкой.
- В копии не указана валюта, поэтому она выбирается при импорте (по умолчанию — из настроек).
- Начальные балансы счетов, бюджеты, долги и регулярные платежи из копии не переносятся.
- Повторный импорт той же копии обновляет записи, а не дублирует их.
- Иконки категорий подбираются по названию. Соответствие номеров иконок 1Money можно задать в
  `ONE_MONEY_ICON_MAP` (`src/importers/oneMoneyBackup.ts`).

### CSV из других источников

- Разделитель `,` или `;` определяется автоматически; кодировка — UTF-8 (с BOM или без) или
  Windows-1251.
- Даты: `dd.MM.yyyy`, `yyyy-MM-dd`, `dd/MM/yyyy`, с временем `HH:mm` или `HH:mm:ss` и без.
  Время считается в часовом поясе из настроек.
- Суммы с запятой или точкой, с пробелами между тысячами.
- Колонки сопоставляются с полями (дата, сумма, валюта, категория, счёт, счёт-получатель,
  заметка, тип) с предпросмотром первых строк. Без колонки «Тип» отрицательная сумма — расход,
  положительная — доход.
- Ошибки показываются по номерам строк. Отсутствующие счета и категории предлагается создать.
- Дубликаты (та же дата до минуты, сумма, счёт и заметка) помечаются и по умолчанию пропускаются.

## Формат CSV экспорта

**Настройки → Экспорт.** Можно выбрать период и счета (фильтр применяется к операциям; счета,
категории, бюджеты, долги и регулярные платежи выгружаются всегда). На телефоне файл
отправляется через меню «Поделиться», на компьютере скачивается. Имя файла:
`akchakana-ГГГГ-ММ-ДД.csv`.

- Кодировка UTF-8 с BOM, разделитель `;`, строки `CRLF`, первая строка — заголовки на русском.
- Поля с `;`, кавычками или переносами строк заключаются в двойные кавычки, кавычки внутри
  удваиваются.
- Один файл со всеми данными. Колонка **«Тип записи»** определяет вид строки: `счёт`,
  `категория`, `бюджет`, `долг`, `повтор`, `операция`. Строки идут в этом порядке.
- Ссылки между записями — по ID. Колонки «Счёт (название)» и «Категория (название)» только для
  чтения человеком и при импорте игнорируются.
- Суммы — десятичные с запятой, без разделителей тысяч, со знаком минус при необходимости
  (`-150,50`); число знаков после запятой — по валюте.
- Даты — ISO 8601 со смещением часового пояса (`2026-03-01T10:00:00+06:00`, миллисекунды —
  только если они не нулевые).
- Логические значения: `да` или пусто.

| Колонка | Счёт | Категория | Бюджет | Долг | Повтор | Операция |
|---|---|---|---|---|---|---|

## Устройство проекта

```
src/
  app/            корневой компонент, нижняя навигация, hash-роутер, тема
  domain/         модель данных, суммы (parseMinor/formatMinor), даты и периоды, балансы,
                  статистика, бюджеты, повторы — чистые функции без UI
  db/             схема Dexie с версиями и миграциями, стандартные категории
  repositories/   интерфейсы хранилища и реализация на Dexie (UI работает только через них —
                  позже можно добавить синхронизацию)
  stores/         Zustand: данные в памяти и состояние интерфейса
  importers/      1Money (sql.js), CSV, собственный формат, определение формата и кодировки
  exporters/      собственный CSV, Web Share API / скачивание
  security/       PIN-код (PBKDF2) и экран блокировки
  features/       экраны: операции, шторка операции, счета и долги, категории, обзор, бюджеты,
                  повторы, импорт и экспорт, настройки, онбординг
  ui/             общие компоненты (шторка, кнопки, поля, тосты, иконки)
tests/            настройка тестов, синтетическая база 1Money, помощники
```

- Суммы хранятся целыми числами в минимальных единицах (тыйын, копейки, центы), валюта — отдельным
  полем. Float не используется ни при разборе, ни при расчётах.
- Даты хранятся в миллисекундах UTC; дни, недели и месяцы считаются в часовом поясе из настроек.
- Схема IndexedDB версионируется: новая версия добавляется в `src/db/dexie.ts` с функцией
  `upgrade`, тест миграции — в `src/repositories/repositories.test.ts`.

## Тесты

`npm run test` запускает модульные тесты и тесты интерфейса (Vitest + Testing Library, IndexedDB
через fake-indexeddb). Импорт 1Money проверяется на маленькой синтетической базе, которую тест
создаёт сам (`tests/makeOneMoneyDb.ts`). Реальные резервные копии и выгрузки с операциями в
репозиторий не добавляются: `.gitignore` исключает `*.sqlite`, `*.db`, `*.csv` и подобные файлы.

## Ограничения

- Курсы валют не загружаются: суммы в разных валютах показываются раздельно.
- Без сервера push-уведомлений напоминания приходят, только когда приложение открыто или
  браузер разбудил его в фоне.
- Данные одного устройства не синхронизируются с другими; перенос — через экспорт и импорт.
