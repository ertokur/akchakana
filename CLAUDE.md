# Акчакана — правила работы с проектом

- Node.js лежит в `C:\Program Files\nodejs` (в Bash: `export PATH="/c/Program Files/nodejs:$PATH"`).
- Перед коммитом: `npm run check` (сборка, тесты, lint) без ошибок.
- Публикация — пуш в `main`: GitHub Actions собирает и выкладывает на GitHub Pages.

## Каждый деплой — новая версия

1. Поднять `version` в `package.json` (0.2.0 → 0.3.0 для новых функций, 0.2.1 для исправлений).
2. Добавить запись в начало `src/changelog.ts`: дата публикации и пункты на русском и английском
   (поровну). Её видно в приложении: «Настройки → Что нового».
3. `npm run check` и пуш. Тест `src/changelog.test.ts` сверяет запись с `package.json`,
   а workflow останавливает публикацию, если тег `v<версия>` уже есть, и ставит тег после деплоя.

Изменения только в `*.md` не публикуются и не требуют новой версии.

## Не делать

- Не коммитить реальные данные пользователя (резервные копии, CSV с операциями).
- Не упоминать сторонние приложения учёта по названию в коде, интерфейсе и описаниях:
  импорт называется «Импорт данных» / «резервная копия».
